# SortRss

SortRss 是一个智能 RSS 聚合、排序与管理工具：把多个订阅源汇总到一处，按你的规则排序与整理。

## 支持平台

| 平台 | 形态 |
| --- | --- |
| Web | 浏览器直接访问（wasmJs / js） |
| Windows | 桌面客户端（exe / msi） |
| Android | 手机 App（APK） |
| 服务端 | 自建后端服务（jar / Docker 镜像） |
